MarkDoc 管理后台

本页是管理员后台入口（独立页面，主站不放置链接、搜索引擎不索引）。 后台为 JavaScript 应用：启用 JavaScript 后，这里将显示管理员登录页 （邮箱 + 密码 + 可选 TOTP；两小时滚动会话，15 分钟内失败 5 次锁定 15 分钟）。

当前部署状态：后端环境未接入。 后台依赖 Supabase（数据库 / 认证 / admin-api Edge Function）。该环境在当前部署中尚未创建， 因此后台与主站的账号体系（登录徽标、匿名计次、云端历史）同处于关闭态。 这不是页面缺失——本入口已随构建部署并可访问。

启用步骤（约 0.5 个工作日）

  1. 创建 Supabase 项目（归属方案见《报价与环境归属》§四）；
  2. 凭据写入 .env.local 后执行 node scripts/deploy-account.mjs（建库、迁移、部署 5 个 Edge Function、配置服务端 secrets、线上自检）；
  3. 仓库 Secrets 配置 VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY 并重新构建部署；
  4. 创建初始超级管理员（Dashboard 建用户 + 一条 SQL），登录本后台创建测试管理员。

详细文档：仓库 docs/账号体系部署.md、docs/账号体系与管理员后台-交付方案.md。
