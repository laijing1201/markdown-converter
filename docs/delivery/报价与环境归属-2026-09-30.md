## 二、部署承诺与清单（甲方要求 1/2 项）

### 依赖关系（透明说明）

账号体系是「前端 + 后端」整体：后端（数据库、认证、Edge Functions）必须运行在 Supabase 上。**创建 Supabase 项目需要注册账号（邮箱+手机），我方无法代为注册**——这是此前一直未部署的唯一卡点，本轮已把其余一切准备到「一键执行」：

```bash
# 凭据写入 .env.local 后，一条命令完成：建库、迁移、部署 5 个函数、
# 配置 secrets、线上自检、打印剩余手工步骤
node scripts/deploy-account.mjs
```
