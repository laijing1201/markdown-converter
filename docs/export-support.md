# MarkDoc 导出支持矩阵

三端共用一条解析管线：`markdownToSafeHtml`（marked + 分页符/图题扩展 + 数学占位 + DOMPurify）产出语义 DOM —— **预览直接渲染它，Word 与 PDF 从它导出**。任何新功能必须同时考虑三列。

- **Preview**：实时预览（`PreviewPanel`），样式由 `DocSettings` 的 CSS 变量驱动。
- **Word**：`src/core/exporter.ts`（docx 库）。
- **PDF**：`src/core/pdf/*`（浏览器实测分页 + pdf-lib），字体子集嵌入。

## 已知限制（PDF）

- Mermaid 与 SVG 图片走 3× 光栅（矢量路径走查器仅用于 KaTeX 的内部 SVG）；
  文字与线条在打印分辨率下清晰，但不是纯矢量。
- 楷体/仿宋等系统字体以内嵌思源宋体/黑体替代（首次导出会提示）。
- 中英混排两段对齐时，空格由阅读器按位置间隙重建（与 Adobe/Chrome 行为一致）。
- 超过一页高度的单张图片会被裁剪（会提示）。
