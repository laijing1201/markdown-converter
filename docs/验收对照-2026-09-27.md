## 一、核心功能（P0）

### 1. 公式转换 Word 原生可编辑 —— **已完成 + 本轮新增自检报告**

- 行内 `$…$`、行间 `$$…$$`、`\(…\)`、`\[…\]` 四类定界符全部识别；LaTeX → MathML → OMML 原生公式，Word 中双击可编辑。
- 下标/上标/分式/根号/积分/矩阵/希腊字母：由 KaTeX→MathML→OMML 管线覆盖（`npm run test` 第一段：12/12 公式全转换）。
- **本轮新增「导出质量自检报告」**：Word 导出成功后弹窗展示——公式 N 个（成功 M 个）、表格 N 张、Mermaid 图 N 张、警告 N 条、耗时；**逐条列出转换失败的公式原文及源码行号**（对照 `extractFormulas` 行号回查，重复公式各归各行）。
- 同步写入导出日志（`core/exportLog.ts`，仅指标不含正文）。

验收：粘贴 `tests/fixtures/caseJ-acceptance.md` → 导出 Word → 查看自检报告弹窗 → 逐个双击公式。

### 2. Mermaid 自动渲染为图片 —— **已完成 + 本轮加固**

- 预览中 mermaid 代码块自动渲染为 SVG（mermaid 10 原生支持 flowchart / sequence / class / state / gantt / pie 等全部常见类型）。
- Word：截图嵌入，**本轮起 3× 采样**（与 PDF 管线一致），打印缩放清晰；PDF：3× 光栅嵌入（既有能力，见 caseD 视觉基线）。
- **本轮新增失败兜底**：渲染失败时预览显示明确错误提示 + **完整保留原始代码**；导出时该图还原为代码块（`data-mermaid-source`），绝不允许代码或 SVG 垃圾以正文文本形式出现。
- 验收：正常图导出后为图片；输入错误语法（如 `graph TD A-`）→ 预览见红框提示+源码、Word 中为代码块。测试：test-docx-xml「Mermaid 无实时容器时还原为源码 / SVG 内容绝不进入正文」。

### 3. 表格转 Word 原生表格 —— **已完成**

- 原生 `w:tbl`，可编辑列宽；表头/正文三线表或底纹样式随模板。
- 合并单元格：colspan → `gridSpan`，rowspan → `vMerge restart/continue`。
- 跨页：行 `cantSplit` 防断裂，**表头行 `tableHeader` 每页重复**（Word 打开即生效）。
- 单元格内公式正常转换（数学占位在表格内同样提取）。
- 测试：test-docx-xml 合并单元格/表头重复/cantSplit 断言。

## 二、内容输入与编辑体验（P1）

### 4. AI 对话链接导入 —— **本轮新增**

- 新增工具栏「🔗 链接导入」：粘贴分享链接（一行一个，**支持多链接合并导入**）→ 抓取 → 提取对话 → 按用户/AI 角色还原为 Markdown（标题、代码块、公式、表格保留）。
- 平台白名单：ChatGPT、DeepSeek、Kimi、豆包、腾讯元宝、文心一言、通义千问；未识别链接明确提示并跳过。
- 架构：`src/core/chatImport.ts`（识别/抓取/三层提取兜底：内嵌 JSON → RSC flight 流 → 通用 HTML→Markdown）；抓取经 `supabase/functions/import-link` Edge Function 代理（仅转发、不存储，SSRF 白名单 + https 强制 + 5MB/15s 上限）。
- 未部署 Supabase 的环境尝试浏览器直连，被 CORS 拦截时给出可操作提示（配置抓取服务或手动复制）。
- 测试：`npx tsx scripts/test-chat-import.ts`（33 项：平台识别、JSON/flight 流/HTML 三路提取、多链接合并顺序、失败隔离、明确报错）。

验收（部署后）：粘贴 DeepSeek 分享链接 → 「抓取并转换」→ 显示消息数 → 「导入到编辑器」→ 左侧出现对话 Markdown → 导出 Word。

### 5. 实时预览面板 —— **已完成（既有能力，本轮复核）**

- 左输入右预览双栏（移动端以「编辑/预览」Tab 切换）；输入即渲染，`useDeferredValue` 并发渲染无 1s 节流，公式/表格/Mermaid 实时可见。
- **预览与导出同一条管线**（`markdownToSafeHtml` + 同一套模板 CSS/样式 + 同一 KaTeX/Mermaid 渲染），批量导出也走 `renderPreviewDom`，保证「预览看到什么、导出就是什么」。

验收：输入含 20 个行内公式的文档，连续编辑观察预览即时更新（验收用例 4）。

### 6. Markdown 输入清洗与规范化 —— **部分完成**

- 已有：粘贴自动修复（未闭合代码块/公式/粗体、表格缺列）+「🪄 修复格式」（列表标记、多余空行、分隔线）+「✨ 智能排版」+「🧩 AI 修复」（定界符混用 `\(...\)`/`$...$` 统一、Word 线性公式还原、全角/零宽字符），修复结果带行号提示。
- 缺口：**清洗前后 diff 侧边栏对照视图**未实现（当前以行号列表形式展示差异）。已列入下轮。

## 三、导出能力增强（P1）

### 7. 更多导出格式 —— **排期中（下一轮）**

- 现有：Word、PDF（真文本、文字可搜索）。
- 缺口：Excel（表格→工作表）、Markdown 打包下载、HTML、纯文本。Word/PDF 之外的格式已排下一轮，优先级按甲方指定顺序让位于批量转换与链接导入。

### 8. 批量转换 —— **本轮新增**

- 工具栏「📦 批量转换」：多选/拖入多个 `.md/.txt` → **统一套用当前模板** → 逐个走完整导出管线（含公式 OMML、Mermaid 截图）→ 打包 ZIP 下载。
- 逐文件进度条 + 结果汇总：每项显示成功/失败与质量摘要（公式 M/N OMML、表格数、图表数）；同名文件自动去重（`报告(2).docx`）；单文件失败不拖垮其它；支持中途取消（已完成文件保留打包）。
- 全程浏览器本地完成，文件不上传。
- 测试：`npx tsx scripts/test-batch-export.ts`（20 项：全管线双文件转换、ZIP 解包核验正文、同名去重、取消语义、进度回调、扩展名过滤）。

验收：选择 10 个 .md → 开始转换 → 下载 ZIP → 解包逐个打开（验收用例 6）。

### 9. 自定义 Word 样式模板 —— **部分完成**

- 已有：三套内置模板（通用文档/学术论文/商务报告）+ 高级设置细调（字体、字号、行距、页边距、页眉页脚、目录、标题编号）+ **另存为我的自定义模板**（本地持久化、工具栏缩略图一键切换）。
- 缺口：**上传 .docx 参考模板并抽取其样式**（Pandoc --reference-doc 等价能力）。涉及 docx 样式解析，已列入下一轮。

## 五、性能与安全（P2）

### 13. 转换性能 —— **部分完成（有度量机制）**

- 导出日志逐次记录耗时/页数（`exportLogSummary` 可查最近导出指标）；PDF 导出全程进度提示、可取消。
- 正常文档（千字级）导出为秒级；含大量公式文档耗时取决于 OMML 转换（有缓存）。10 万字大文档的 30s 预算需真机压测数据，下一轮补充专项压测报告（`npm run test:pdf:stress` 已有基建）。

### 14. 数据安全与隐私 —— **已完成（含本轮边界）**

- 全部转换（含 PDF 字体子集化、批量转换）在浏览器本地完成，正文不上传服务器（预览区常驻「🔒 本地处理」标识）。
- 导出日志只记指标与错误摘要，**不含正文与公式原文**；诊断信息不含聊天正文。
- 导出文件不嵌入用户身份信息。
- 本轮新增的链接导入代理（import-link）仅做一次性转发：不落库、不写日志，白名单 + https 强制。
- 竞品式隐私声明文案已在 README 与扩展权限说明中明确。
